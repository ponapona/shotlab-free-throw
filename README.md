# ShotLab — フリースロー動作解析

動画から身体の座標・関節角度・時系列波形とボールの2D軌道を抽出し、CSVにするブラウザアプリです。選手間・選手内の**フォームの傾向**を調べるための、探索・データ整理用の初版です。

**v0.3.0 / 試作版。高精度を実証した測定器ではありません。** 基準計測との角度・位置誤差の検証は未実施です。PCAとフォームの良否判定は含みません。

## できること

- 動画を選択し、対象選手の範囲を指定して、MediaPipe Heavyで33点の姿勢を推定。
- Google MediaPipeの全33点を保持し、顔・指先を除いた主要16点を標準表示。主要16点CSVと全33点CSVは別ボタンで保存。
- EfficientDet-Lite2と背景差分で小さな白・橙系のボール候補を検出。手元との整合・飛行の継続から放物線を復元。
- 自動検出がなくても3時刻の点を指定して放物線補間。見える観測点と見えない位置の仮定点を区別。
- ボール中心をクリックして修正・欠測指定・修正の取り消し。自動検出の元座標を保持。
- 専用のボール軌道CSVに、自動候補・手修正・採用座標・放物線の事後推定を別列で保存。
- 左右の肘・膝・肩・股・足首の2D内角、体幹の傾き、角速度を計算。
- 動画・骨格・波形を同期再生。低可視性の角度は欠測として残す。
- シュート区間の候補を出し、時刻と成功／失敗／未確認を人が修正。
- 平均・中央値・標本SD・IQR・可動域・有効点数、局面別の統計、時間正規化波形、10特徴のPCA候補CSVを保存。
- 選手ID・測定ID・シュートする手を記録。主要16点と全33点の別出力、解析設定JSON、復元用セッションJSONを保持。

**自動検出・背景差分ともに位置精度は未検証です。** 小さい球・遮蔽・複数の球では欠測や誤検出があります。背景を球と誤認する場合もあるため映像で確認し、必要な点を修正してください。放物線は画像候補、3点以上の手動観測、明示した仮定点から復元し、根拠を別列で保存します。仮定を含む軌道は観測軌道と同等に扱いません。実空間の3D弾道・速度・入射角や成功失敗の自動判定は含みません。個人動画・検証用の解析値は公開用ソースに含めていません。

以前の版から更新する場合は [更新手順](docs/upgrade-v0.3.md) を参照してください。

## 最初に動かす（Windows / macOS / Linux）

Node.js 22.13以上（22系または24系）をインストールしてください。

1. このプロジェクトをダウンロードし、ZIPなら展開します。
2. `package.json` があるフォルダーでPowerShellまたはターミナルを開きます。
3. 以下を1行ずつ実行します。

```sh
npm ci
npm run setup:assets
npm run dev
```

ターミナルに表示されたURL（通常 `http://localhost:5173`）をChrome / Edgeで開きます。PowerShellで `npm.ps1` の実行制限が出る場合は、同じコマンドの `npm` を `npm.cmd` にしてください。止めるときは `Ctrl+C`。

`setup:assets` は公式配布のモデルをダウンロードし、SHA-256を確認します。初回セットアップには通信が必要です。解析動画を外部の推論サービスへ送信する処理はありません。静的Web版では端末のブラウザで解析します。動画長・端末性能により時間がかかるため、まず5〜10秒の動画で試してください。ブラウザ推論はメインスレッドで動くため、処理中に操作が重くなることがあります。

## 使い方

1. **動画をインポート**で動画を選択。
2. 選手1人の全身と、シュート中に手足が動く範囲を囲む。
3. **ボールの範囲**に切り替え、手元からリングまでの飛行範囲を囲む。初期値は映像全体。
4. **解析を開始**。ブラウザ版は毎秒15または30サンプル。身体→ボールの順に処理。
5. シュート候補を映像で確認し、**時刻を編集**でリリース等を修正。
6. 結果を成功／失敗／未確認から選択。
7. 軌道が不足する投を選び、**3点から軌道を復元**。時刻を動かし、手離れ直後・飛行中・接触前の点を映像でクリック。
8. **CSVエクスポート**で選手ID・測定ID・シュートする手を入力し、データと**解析設定JSON**を保存。
9. 続きを作業する場合は**セッションJSON**も保存。

復元は、同じ動画をインポート画面で選び、**保存セッションを復元**でJSONを指定します。動画のSHA-256が一致すると再推論せず復元します。ページを閉じるとメモリ上の解析は消えるため、必要な結果を保存してください。

| 出力              | 1行の単位           | 用途                                                        |
| ----------------- | ------------------- | ----------------------------------------------------------- |
| `*_pca.csv` | 1投 | シュートする側をそろえた10特徴。PCA入力の初期候補 |
| `*_phases.csv` | 1投×局面 | セット・シュート動作・リリース後の統計 |
| `*_waveforms.csv` | 1投×局面×正規化時刻 | 0〜100%、51点の波形と補間状況 |
| `*_shots.csv`     | 1投                 | フォーム特徴量の比較・PCAの準備                             |
| `*_frames.csv`    | 1フレーム／サンプル | 角度・角速度・波形の分析                                    |
| `*_body.csv`      | 1サンプル×主要16点  | 顔などを除いた座標分析                                      |
| `*_landmarks.csv` | 1サンプル×全33点    | 生データの保存・再検証                                      |
| `*_ball.csv`      | 1サンプル           | ボール自動候補・手修正・採用点・放物線。欠測も1行として保存 |
| `*_metadata.json` | 1動画               | バージョン・設定・動画識別・区間確認                        |
| `*_session.json`  | 1動画               | 座標・設定・時刻・ラベルをまとめて復元                      |

CSVはUTF-8 BOM付き、欠測は空欄です。未確認を失敗の0に変換しません。`source_sha256` で動画との対応、`app_version` で特徴量処理の版を記録します。**CSVとmetadata JSONをセットで保管**してください。

## 開発者向け

画面はReact + Vite、解析コアは通常のJavaScriptモジュールです。専用サーバー、APIキー、有料AI契約は不要です。

```sh
npm test
npm run build
npm run preview
```

ビルド結果は `dist/`。GitHub Pages / Hugging Face Static Spacesへ配信できます。ブラウザ解析用のモデル・WASMが必要なので、クリーンな環境では先に `npm run setup:assets` を実行してください。

- `src/`：画面とスタイル。
- `public/engine.mjs`：角度、平滑化、投区間候補、CSV。
- `public/analyzer.mjs`：ブラウザ推論／ローカルCPU解析の呼び出し。
- `public/ball-analyzer.mjs`：ブラウザでボールの検出。
- `public/ball-tracking.mjs`：候補の関連付け・手修正の適用・ボールCSV。
- `public/ballistics.mjs`：画像候補・手動観測・仮定点からの放物線復元。
- `public/ball-motion.mjs`：背景差分による小球候補。
- `public/shot-statistics.mjs`：局面別統計・正規化波形・PCA候補。
- `public/dictionary.mjs`：CSV列の定義。
- `analysis/`：CPU解析、CSV・説明書の生成。
- `tests/`：計算・欠測・因果性・CSV・放物線の自動検査。

設定変更は `config/defaults.json` で行い、`npm run docs` を実行します。`public/settings.mjs` は生成物です。保存セッションは元の解析設定を優先し、再計算したアプリ版を `processing_version` に記録します。モデル変更は再推論が必要です。

### ボールと身体のデータを選ぶ

- 身体フォームの比較：モーション欄の **主要16点 CSV**。左右の肩・肘・手首・股関節・膝・足首・かかと・つま先です。
- 元データの保存：**全33点 CSV**。顔・指先も含みます。16点へ絞っても元のMediaPipe番号を変えません。
- シュート軌道：**軌道 CSV** またはCSVエクスポートの **ボール軌道 CSV**。

「ボール位置を修正」を押し、一時停止中の映像で球の中心をクリックします。前後のフレームへ進み、見えない点は欠測にするか、点の種類を「仮定点」に変えて推測位置を明示します。仮定点を含む曲線全体には印が付きます。誤検出を消す場合も「この点を欠測に」を使います。自動候補は灰、手修正は緑、放物線は橙の破線です。手修正や区間変更後はCSVとセッションJSONを保存し直してください。

軌道パネルは選択した投の全区間を表示し、点をクリックするとその時刻へ移動します。放物線を出すには、シュート一覧の「時刻を編集」で離手時刻・終了時刻を映像と合わせてください。自動候補がない投は「区間を追加」で作成できます。
