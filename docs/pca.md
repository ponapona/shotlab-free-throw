# PCAでフォームの傾向を見る前に

この初版は特徴量の抽出までです。PCA計算・選手の自動分類・強み弱みの採点は実装していません。

1. 同じ撮影方向・画角・fps・利き手の扱いを決めます。左右を反転して比較する場合は、その処理も記録します。
2. 投区間、特にリリースを映像で確認します。未確認の候補のまま比較しないでください。
3. `shots.csv` を結合し、動画の `source_sha256` と対応する `player_id` / `session_id` を別表で管理します。同じ動画内の `shot_id` だけでは全体で一意になりません。
4. まず8〜10程度の身体特徴量を選びます。例：左右の膝・肘のリリース時角度、膝の最小角度、体幹傾斜。似た変数を大量に追加して特定の動きを過大評価しないようにします。
5. `*_valid_fraction` を調べ、欠測の除外・補完方針を先に決めます。空欄を0に置き換えません。
6. 単位・分散をそろえる標準化後、全選手を共通のPCA軸に載せます。選手ごとに別々にPCAを行うと得点を直接比較できません。
7. 負荷量を読んで「膝の曲げが深い傾向」などと解釈します。得点の高低を上手さの順位にしません。
8. 選手ごとの平均得点だけでなく、同じ選手の投ごとの散らばりも表示します。

`success`、各ID、ファイル識別、確認状態、ボールの事後補正係数は、最初の身体フォームPCAへ自動的に全部投入しないでください。成功率との関係は別の分析課題です。学習と評価を行う場合は選手／セッション単位で分割し、標準化・欠測補完・PCAの学習も訓練データ内で行います。

波形全体をPCAへ渡す場合は別の設計が必要です。投の開始〜リリース等を共通の時間軸へそろえる処理、補間、欠測の扱いを明示してください。現在の波形は元の動画時刻上の値で、投ごとの時間正規化はしていません。
