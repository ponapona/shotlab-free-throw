# 選手ごとのフォームの傾向を見るために（v0.3）

PCA計算・選手の自動分類・上手さの採点は、このアプリには含みません。v0.3は「1投ずつ、同じ意味の特徴を並べられるデータ」を作ります。

## どのCSVを使うか

- `shots.csv`：1行＝1投。開始〜リリースの11角度について、最小・最大・平均・中央値・標本SD・IQR・可動域・有効点数・有効割合・リリース時角度。ボール係数は事後情報として別名で保存。
- `phases.csv`：1行＝1投×局面。セット、シュート動作、リリース後を混ぜずに統計を比較。
- `waveforms.csv`：1行＝1投×局面×0〜100%の時刻。各局面51点。長い欠測は埋めず、短い間隔の線形補間を明示。時間の長さも保存。
- `pca.csv`：1行＝1投。下の10特徴を選んだ初期候補。PCA入力として研究上妥当と検証した変数群ではなく、検討の出発点。

全CSVの全列を一度にPCAへ入れないでください。例えば最小・最大・可動域には厳密な関係があり、平均と中央値も似ています。重複する変数を大量に入れると、一つの関節の特徴を過大に重くします。

## 初期候補の10特徴

| カラム | 意味 |
|---|---|
| `shooting_elbow_deg_at_release` | シュートする側のリリース時肘内角 |
| `shooting_shoulder_deg_at_release` | 同側のリリース時肩内角 |
| `shooting_knee_deg_min_pre` | 同側の開始〜リリースの膝最小内角 |
| `shooting_hip_deg_min_pre` | 同側の開始〜リリースの股最小内角 |
| `trunk_lean_deg_at_release` | リリース時の体幹傾斜 |
| `shooting_elbow_deg_mean_drive` | シュート動作中の同側肘の平均 |
| `shooting_knee_deg_median_setup` | セット中の同側膝の中央値 |
| `shooting_elbow_deg_rom_pre` | 開始〜リリースの同側肘の最大−最小 |
| `shooting_knee_deg_rom_pre` | 開始〜リリースの同側膝の最大−最小 |
| `drive_duration_s` | シュート動作開始〜リリースの秒数 |

平均と中央値の両方は保存しますが、同じ関節・同じ局面の代表値は原則として片方を選び、他方への置換で結果の安定性を確認します。外れ値が目立つデータでは中央値・IQRが比較しやすい一方、誤検出そのものは先に確認・修正します。SD/IQRは「その1投の動作中の広がり」であり、「投ごとの再現性」ではありません。再現性は複数投の特徴・PCA得点の散らばりから調べます。

## 比較の条件と品質

1. 同じ撮影側・高さ・距離・画角をそろえます。2D角度は撮影方向に依存します。手の左右をそろえてもカメラの違いは除去できません。体幹傾斜の左右符号は自動反転しないため、同じ撮影方向で比較します。
2. 動画ごとに選手ID、測定ID、シュートする手を入力し、投区間を映像で確認します。1動画1選手が前提です。異なる動画のshot_idだけをキーにしません。
3. `pca_ready=1` は、選手ID・投げる手・時刻確認・10個の有限値・正の動作時間を満たす行。集計特徴には有効割合0.8以上・有効3点以上を要求します。この閾値は初期設定で、妥当性を検証済みの値ではありません。
4. `pca_ready=0` の行は原因を調べます。空欄を0に変換しません。除外で残った投数・選手ごとの欠測率も報告します。
5. `success`、ID、確認フラグ、可視性や有効割合はPCAへ入れません。撮影・検出の良し悪しが主成分になるのを避けるためです。結果は後から色分け・関連分析に使います。

## PCAと選手比較

- 採用した特徴を全選手共通で標準化し、同じPCAモデルで得点を出します。scikit-learnのPCAは平均中心化しますが、各特徴の分散をそろえる標準化は自動ではありません。
- 選手ごとに別々のPCAを行うと得点を直接比較できません。選手ごとの投数が大きく違う場合は、等数抽出や重みの方針を決め、多投選手に軸が引かれないか確認します。
- 選手の傾向には主成分得点の平均または中央値、同一選手内の変動にはSDやIQRを使います。選手と測定日の階層を区別します。
- 各成分を負荷量から「膝を深く曲げる傾向」等と解釈します。PC1が大きい＝良いフォーム、ではありません。PCA自体は選手を群分けする手法ではありません。
- 変数数に対して独立した選手・測定日の数を確保し、選手／測定日単位の再標本化などで負荷量・解釈の安定性を調べます。投の総数だけを独立標本数と考えません。
- 予測・汎化評価を行う場合は選手／測定日単位で分割し、欠測補完・標準化・PCAの学習は訓練側だけで行います。

## 軌道を使う分析

身体フォームのPCAと、ボール軌道のPCAはまず別に設計します。画素座標・速度係数は画角、距離、カメラ位置に依存します。単に画像幅・高さで割るだけでは選手間の物理量比較になりません。

`ball_fit_n_assumed>0` の曲線は人の仮定を含みます。身体の動きから仮定した球の位置を、身体特徴と同じPCAに入れると、入力した仮定を再発見する循環になります。独立した観測・校正を用いるか、仮定を含む解析を感度分析として分けてください。観測に基づく補間であっても、候補に対するRMSEを真の位置精度と解釈しません。

波形PCAでは、局面・関節・正規化時刻を列へ展開する前に採用変数と欠測方針を決めます。少数の選手に全11角度×153点をそのまま入れて確かな分類ができるわけではありません。
