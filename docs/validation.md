| `npm install`による初回依存関係インストール | package-lockを生成。公開npmレジストリを参照 |
| SDK資産の配置・モデルSHA-256 | 一致 |
| `npm test` | 10件成功 |
| `npm run build` | 成功。Viteの静的成果物を生成 |
| TypeScriptコマンド | エラーなし。ただし既存画面App.tsxは `@ts-nocheck` を保持 |
| Pythonの構文検査 | 成功 |
| 短い実動画のCPU推論 | 約2秒・60フレーム中60フレームで33点を出力 |
| 上記データのCLI出力 | フレーム60行、全点1,980行、主要16点960行 |

テストの対象は、既知の角度と縦横比、低可視性/presenceによる欠測、平滑化の因果性、主要点の選択、ラベルの非混入、CSV欠測・エスケープ、データ辞書の一致、設定の記録・再利用、不正データの拒否、放物線の外れ値・欠測処理です。

## 配布ZIPの再確認 — 2026-10-28

初回の配布ZIPには `components/ui/` の6ファイルが欠けていました。開発用フォルダーでのビルド成功を、配布ZIPでも成功するものとして案内した点を訂正します。ZIP作成時にトップ階層の `ui/` を除外する指定が、必要な `components/ui/` にも適用されていました。

修正版は、元の6ファイルを収録し直しました。検証は修正版ZIPを空のフォルダーへ展開した状態で行い、`npm ci`、`npm run setup:assets`、`npm test`、`npm run build` を確認しています。公開設定の `.github/workflows/check.yml` と `.github/workflows/pages.yml`、`.gitignore` もZIP内に収録しています。

この修正により、上記のブラウザ操作・推論精度・OSごとの未検証事項が解消したわけではありません。
