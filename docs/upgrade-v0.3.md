# v0.3への更新と最初の操作

## GitHubへ反映する

1. `ShotLab-GitHub-v0.3.0.zip` を右クリックし、「すべて展開」を選びます。
2. 中の `shotlab-github` を開き、`src`、`public`、`components`、`package.json` が同じ場所に見える状態にします。
3. https://github.com/ponapona/shotlab-free-throw の **Code** を開きます。ブランチは **main**。
4. **Add file → Upload files** を押します。
5. `shotlab-github` の中身をすべて選び、アップロード欄へドラッグします。ZIPや外側のフォルダーごとではありません。
6. Commit changes欄に `Update ShotLab to v0.3.0` と入力し、**Commit directly to the main branch** を選び、緑の **Commit changes**。
7. **Actions → Publish GitHub Pages → Run workflow → Branch: main → 緑のRun workflow**。
8. 最新の実行が **Success** になったら https://ponapona.github.io/shotlab-free-throw/ を開き、**Ctrl+F5**。
9. 画面上部に **v0.3.0** があることを確認します。既存のリポジトリやPages設定を作り直す必要はありません。

## 既存のデータを使う

同じ動画を選択し、保存済みのセッションJSONを復元すると、身体を再推論せず使えます。ボール候補が不足する場合は **動きからボールを再検出** を押してください。固定カメラで白・橙系の小球に向いた処理です。保存時のボールROIを使います。

## 自動軌道が不足する場合

1. シュート一覧で対象の投を選択。**時刻を編集**でリリースと終了を確認します。候補がなければ**区間を追加**。
2. **3点から軌道を復元**を押します。離手直後のサンプルへ移動します。
3. 「観測点：ボールが見える」を選び、動画のボール中心をクリック。
4. 再生バーや1フレーム前／後で飛行中の別時刻に移動し、2点目をクリック。
5. リングに触れる前の時刻に移動し、3点目をクリック。異なる3時刻が最低限です。前半・中間・後半に離して置くと形を決めやすくなります。
6. 橙の放物線と「放物線を復元」の表示を確認。指定時刻のボタンで各点へ戻れます。点を修正するには同じ時刻で再クリック、取り消すには**この点の修正を戻す**。
7. ボールが見えない時刻の位置を推測して置く場合は、点の種類を**仮定点：位置を推測して置く**へ変更します。紫の丸になります。仮定点は観測列に混ざらず、曲線全体にも仮定依存の印が付きます。
8. **軌道CSV**と**セッションJSON**を保存します。補間は指定した最初〜最後の時刻の間だけです。3点で合うことは精度の証明にはなりません。

## 平均・中央値やPCA候補を保存する

1. **CSVエクスポート**を開き、選手ID・測定ID・シュートする手を入力。
2. **シュート単位CSV**：最小最大に加え、平均・中央値・SD・IQR・可動域・有効点数。
3. **局面別の統計CSV**：セット、シュート動作、リリース後を別々に集計。
4. **時間をそろえた波形CSV**：各局面0〜100%の51点。補間・欠測を区別。
5. **PCA候補CSV**：初期候補の10特徴と選手IDなど。PCA計算そのものではありません。
6. **カラム説明CSV／データの読み方HTML**も新しい版で保存します。

詳しい入力変数の選び方は [pca.md](pca.md)、計算は [methods.md](methods.md)、確認範囲は [validation.md](validation.md) を参照してください。
